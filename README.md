# نظام طلبات الدعم الفني (IT Support Requests System)

نظام تذاكر دعم فني — Flask + SQLite/Postgres + Render، مبني على نفس بنية نظام الحجوزات
السابق (PWA قابل للتثبيت، بريد إلكتروني عبر Microsoft Graph، إشعارات Push حقيقية).

## فكرة النظام

- المعلمون فقط (الموجودون ضمن قائمة معتمدة) يمكنهم تقديم طلب دعم فني.
- كل تذكرة تحصل على **رقم تسلسلي** (للوحة التحكم) و**رقم عشوائي للاستعلام** (يُرسل
  للمعلم/ة عبر البريد الإلكتروني مع الرقم التسلسلي).
- ثلاث مستويات موظفين: **دعم فني**، **مسؤول نظام**، **مدير عام** — كل مستوى يملك
  صلاحيات المستوى الذي تحته بالإضافة لصلاحياته الخاصة.

## الصفحات العامة

| المسار                       | الوصف                                  |
| ----------------------------- | --------------------------------------- |
| `/`                            | الصفحة الرئيسية                         |
| `/ticket`                      | نموذج تقديم طلب دعم جديد                |
| `/lookup`                      | استعلام عن تذكرة برقم التتبع            |
| `/ticket/<tracking_code>`      | صفحة حالة التذكرة + التعليقات           |

## لوحة التحكم

| المسار         | الوصف                          |
| -------------- | ------------------------------- |
| `/admin`       | لوحة التحكم الرئيسية (التذاكر) |
| `/admin/login` | تسجيل الدخول                    |

أول حساب "مدير عام" يُنشأ تلقائياً من متغيرات `ADMIN_USER` / `ADMIN_PASS` عند أول تشغيل.
من داخل لوحة التحكم (تبويب "الموظفون") يمكن للمدير العام إنشاء حسابات دعم فني ومسؤولي نظام إضافيين.

## الصلاحيات

- **دعم فني**: التعليق، إغلاق/إعادة فتح، أرشفة، دمج تذاكر — على التذاكر المعينة له فقط.
- **مسؤول نظام**: كل صلاحيات الدعم الفني + على أي تذكرة + تعيين/إلغاء تعيين/إعادة تعيين + إدارة التصنيفات وقائمة المعلمين.
- **مدير عام**: كل ما سبق + إدارة حسابات الموظفين (إضافة/تعديل/تعطيل/حذف).

## النشر على Render

```
git init
git add .
git commit -m "initial commit"
git remote add origin https://github.com/YOUR_USER/acs-ticketing.git
git push -u origin main
```

- **Build Command:** `pip install -r requirements.txt`
- **Start Command:** `gunicorn app:app --workers=1 --bind=0.0.0.0:$PORT --timeout=120`
- **Disk:** أضف Persistent Disk حجمه 1GB على المسار `/data`

### متغيرات البيئة (Environment Variables)

| المتغير           | الوصف                                          |
| ------------------ | ------------------------------------------------ |
| `SECRET_KEY`        | مفتاح سري عشوائي                                 |
| `ADMIN_USER`        | اسم مستخدم أول حساب مدير عام                    |
| `ADMIN_PASS`        | كلمة مرور أول حساب مدير عام                     |
| `ORG_AR` / `ORG_EN` | اسم المؤسسة بالعربية / الإنجليزية               |
| `LOGO_URL`          | رابط شعار المؤسسة                                |
| `MS_TENANT_ID`      | معرّف المستأجر في Microsoft 365 (لإرسال البريد) |
| `MS_CLIENT_ID`      | معرّف تطبيق Azure AD                             |
| `MS_CLIENT_SECRET`  | السر الخاص بتطبيق Azure AD                       |
| `MS_SENDER_EMAIL`   | صندوق البريد المرسِل (Graph API)                |

## قاعدة البيانات

SQLite افتراضياً (أو Postgres عبر `DATABASE_URL`) — تُنشأ تلقائياً عند أول تشغيل.

### الجداول الرئيسية

- `tickets` — التذاكر
- `ticket_comments` — سجل المتابعة/التعليقات
- `teachers` — قائمة المعلمين المعتمدين
- `categories` / `category_items` — التصنيفات وعناصرها الفرعية
- `staff_users` — حسابات الموظفين (دعم فني / مسؤول نظام / مدير عام)
